# StreamSelect für Kodi 21 Omega

StreamSelect Installer 1.2.2.9 mit StreamSelect Home (Vorschau) 0.1.1.

1. Falls das Repository noch fehlt, [StreamSelect Repository 1.0.2 herunterladen](https://raw.githubusercontent.com/pawo81/streamselect-kodi/main/repository.streamselect-1.0.2.zip) und in Kodi unter **Add-ons → Aus ZIP-Datei installieren** öffnen.
2. Unter **Aus Repository installieren → StreamSelect Repository → Programm-Add-ons** den **StreamSelect Installer** installieren oder aktualisieren.
3. Falls **StreamSelect Home (Vorschau)** bereits aktiv ist, vor dem Skin-Update unter **Einstellungen → Benutzeroberfläche → Skin** kurz zu **Estuary** wechseln.
4. Den Installer öffnen und **StreamSelect Home (Vorschau) installieren / aktualisieren** ausführen.
5. Kodi neu starten und unter **Einstellungen → Benutzeroberfläche → Skin** die **StreamSelect Home (Vorschau)** auswählen.

## Updates

Ist das Repository bereits installiert, kann Kodi den Installer und die Skin-Pakete über **Add-ons → Verfügbare Aktualisierungen** beziehen. Falls die neue Version noch nicht angezeigt wird, in der Add-on-Verwaltung **Nach Aktualisierungen suchen** wählen.

Der bisherige Skin **StreamSelect Home 0.2.6** bleibt über das Repository verfügbar. Die neue Oberfläche wird als separater Skin installiert.
