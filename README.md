# StreamSelect für Kodi 21 Omega

StreamSelect Installer 1.2.2 · Build 2 · StreamSelect Home 0.2.6

1. [StreamSelect Repository herunterladen](https://raw.githubusercontent.com/pawo81/streamselect-kodi/main/repository.streamselect-1.0.2.zip).
2. Die Repository-ZIP in Kodi unter **Add-ons → Aus ZIP-Datei installieren** auswählen.
3. Unter **Aus Repository installieren → StreamSelect Repository → Programm-Add-ons** den **StreamSelect Installer** installieren.
4. Den Installer öffnen und **StreamSelect mit Home installieren / aktualisieren** ausführen.
5. Kodi neu starten und unter **Benutzeroberfläche → Skin** StreamSelect Home wählen.

## Updates

Kodi kann das Repository, den Installer, StreamSelect Home und seine beiden Hilfs-Add-ons automatisch aktualisieren. Unter **Einstellungen → System → Add-ons → Updates** kannst du **Updates automatisch installieren** oder **Benachrichtigen, aber keine Updates installieren** wählen. Im zweiten Fall findest du neue Versionen unter **Verfügbare Aktualisierungen**.

Wenn Home bereits mit dem Installer eingerichtet wurde, wähle einmal **Aus Repository installieren → StreamSelect Repository → Look and Feel → Skins → StreamSelect Home** und installiere die Repository-Version. Ihre Abhängigkeiten sind **StreamSelect Home Launcher** und **StreamSelect Skin Helper**. Falls Kodi für eines der beiden bereits installierten Hilfs-Add-ons weiterhin keine Updates anbietet, wähle in dessen Add-on-Details unter **Versionen** einmal die Version aus dem StreamSelect Repository.
