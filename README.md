# StreamSelect für Kodi 21 Omega

StreamSelect Installer 1.2.2.11 mit dem Skin StreamSelect 1.0.1.

1. Falls das Repository noch fehlt, [StreamSelect Repository 1.0.2 herunterladen](https://raw.githubusercontent.com/pawo81/streamselect-kodi/main/repository.streamselect-1.0.2.zip) und in Kodi unter **Add-ons → Aus ZIP-Datei installieren** öffnen.
2. Unter **Aus Repository installieren → StreamSelect Repository → Programm-Add-ons** den **StreamSelect Installer** installieren oder aktualisieren.
3. Falls **StreamSelect** bereits aktiv ist, vor dem Skin-Update unter **Einstellungen → Benutzeroberfläche → Skin** kurz zu **Estuary** wechseln.
4. Den Installer öffnen und **StreamSelect Home installieren / aktualisieren** ausführen.
5. Kodi neu starten und unter **Einstellungen → Benutzeroberfläche → Skin** den Skin **StreamSelect** auswählen.

## Optionale Video-Add-ons

Der Installer bietet xStream, xShip, xVAULT und Cumination zur Auswahl an. Über **Optionale Video-Add-ons installieren** lässt sich die Auswahl später öffnen. Kodi installiert die gewählten Add-ons über die angebotenen Quellen und fragt vor der Installation nach.

## Automatische Updates

Ist automatische Aktualisierung in Kodi aktiviert, erhalten aus dem StreamSelect Repository installierte Add-ons neue Versionen beim nächsten Update-Check. **Nach Aktualisierungen suchen** startet die Prüfung sofort.

Nach einer manuellen ZIP-Installation einmal in den Add-on-Informationen unter **Versionen** die Version aus **StreamSelect Repository** auswählen. Das gilt für den Installer und den Skin sowie bei Bedarf für den Home Launcher. Bei einem älteren StreamSelect-Skin, in dem die Add-on-Informationen fehlen, zum Umstieg vorübergehend **Estuary** wählen.

Der bisherige Skin **StreamSelect Home 0.2.6** bleibt über das Repository verfügbar. Die neue Oberfläche wird als separater Skin installiert.
